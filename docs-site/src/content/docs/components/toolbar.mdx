## Vertical Toolbar

The main sidebar toolbar with grouped icon buttons.

### Preview

<ComponentPreview story="toolbar" height="560px" />

### Usage

<CodeBlock code={`use skyscope_design_system::composites::{toolbar, ToolbarItem, ToolbarGroup};
use skyscope_design_system::icons::*;

let groups: Vec<ToolbarGroup> = vec![
    vec![
        ToolbarItem::new(ICON_LAYERS),
        ToolbarItem::new(ICON_MAP),
    ],
    vec![
        ToolbarItem::new(ICON_SETTINGS),
    ],
];

let response = toolbar(ui, &theme, &groups, Some(0), &[]);`} />

## Top Toolbar

A horizontal toolbar with title, clock, and icon buttons.

<CodeBlock code={`use skyscope_design_system::composites::{top_toolbar, StatusField, StatusFieldKind, ToolbarAction};
use skyscope_design_system::icons::*;

let fields = [
    StatusField { label: "UTC", value: "12:34:56", kind: StatusFieldKind::Normal },
    StatusField { label: "QNH", value: "1013", kind: StatusFieldKind::Normal },
];
let actions = [
    ToolbarAction { icon: ICON_SETTINGS, selected: false, disabled: false },
    ToolbarAction { icon: ICON_SEARCH, selected: false, disabled: false },
];

let response = top_toolbar(
    ui, &theme,
    "APP TITLE",
    &fields,
    &actions,
);`} />

## Zoom Toolbar

Compact zoom controls with +/- and reset.

<CodeBlock code={`use skyscope_design_system::composites::zoom_toolbar;
use skyscope_design_system::icons::*;

let response = zoom_toolbar(ui, &theme, rect, ICON_PLUS, ICON_MINUS);`} />
